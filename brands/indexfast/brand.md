## Facts that may be used (source: the site, 2026-11-13)

- Watches the sitemap and submits new or updated URLs to IndexNow engines: Bing, Yandex, Naver, Seznam, Yep.
- Pro and Unlimited: direct Bing Webmaster API, Yandex recrawl, Baidu URL push, using the user's own keys.
- Google: Search Console connection and sitemap resubmission. Indexing API only for eligible job and livestream pages.
- MCP server, REST API, CLI and SKILL.md so AI tools can submit pages.
- URL diagnostics: noindex tags, canonical mismatches, redirects, robots.txt blocks, HTTP errors.
- Batching (IndexNow up to 1,000 URLs, Bing 100), 429 handling with a circuit breaker, jittered retries, live queue.
- Free tools: Google index checker, bulk index checker, sitemap URL extractor, IndexNow key generator.
- Setup takes about two minutes. Free plan needs no credit card.
- Pricing per 30 days, prepaid, no auto-renewal: Free $0 (1 site, 500 URLs, daily checks), Pro $19 (10 sites, 10,000 URLs per site, hourly), Unlimited $99 (unlimited sites, 50,000 URLs per site per sync, hourly).

## Never claim

- That Google indexing is guaranteed, or that Google accepts IndexNow. The site says it does not.
- Any speed-up, ranking or traffic number. The site publishes none.
- Re-check the site before using a price or limit; they can change.
